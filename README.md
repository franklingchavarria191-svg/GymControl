# GymControl 

**Sistema de Gestión de Gimnasio — Proyecto PAE**

## Descripción del proyecto

GymControl es un sistema desarrollado en Visual Basic .NET con Windows Forms y MariaDB, diseñado para administrar las operaciones de un gimnasio.

Permite gestionar socios, membresías, pagos, horarios y consultar información mediante reportes.

## Módulo de reportes

El proyecto contempla nueve reportes:

1. Recibo de pago.
2. Constancia de membresía.
3. Listado de membresías por vencer.
4. Ingresos por período.
5. Estado de cuenta del socio.
6. Horario semanal.
7. Saldos pendientes.
8. Informe gerencial mensual.
9. Libro de ingresos anual.

**Estado actual:** las nueve consultas de datos fueron probadas exitosamente. La generación y presentación de los reportes continúa en desarrollo.
